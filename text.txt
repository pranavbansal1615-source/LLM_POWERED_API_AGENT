📖 Abstract

This project introduces an autonomous Smart API Agent that:

Converts unstructured API documentation → executable code
Uses a RAG (Retrieval-Augmented Generation) pipeline
Ensures:
✅ Zero hallucination responses
✅ Secure execution using WebAssembly sandbox
✅ Accurate, document-grounded answers
🚨 Problem

Developers waste time:

Searching large API docs
Figuring endpoints, headers, parameters manually
🎯 Solution
AI reads documentation
Generates ready-to-run Python code
Executes safely in-browser
🧠 Core Concept: Retrieval-Augmented Generation (RAG)
What is RAG?
Combines:
LLMs (generation)
External knowledge base (retrieval)

👉 Result:

Context-aware
Accurate
Real-world grounded responses
⚠️ Challenge in Traditional RAG

Build a:

Modular
Low-latency
Efficient RAG system
using Python + React stack
⚙️ System Architecture
🔹 Backend
Python + FastAPI
Asynchronous request handling
🔹 Frontend
React.js
Real-time UI
🔹 Vector Database
FAISS / ChromaDB
🔄 Pipeline Workflow
1. Data Ingestion
Parse documents
Split into chunks
2. Embedding Generation
Sentence-transformers convert text → vectors
3. Vector Search
k-NN retrieves relevant chunks
4. Content Generation
Context injected into LLM
Generates response + code
🧮 Technical Foundations
🔹 Similarity Metric
Cosine similarity between vectors
🔹 Chunking Strategy
Fixed size chunks
10–20% overlap
🔹 Embedding Size
384–768 dimensions
🔹 Indexing
HNSW (Hierarchical Navigable Small World graphs)
🔐 Security & Safe Execution
🛡️ Sandbox Execution
Python runs in Pyodide WebWorker (browser)
⚡ WebAssembly (WASM)
No OS-level access
Blocks malicious code (e.g., os.system())
⚙️ Async Processing
Deno handles heavy tasks
FastAPI remains responsive
🧪 Methodology (Detailed Flow)
Upload API PDFs
Parse using LangChain
Convert text → embeddings
Store in ChromaDB
Query → semantic search
Send context to LLM (DeepSeek-R1)
Generate:
Answer
Python code
Regex processing:
Remove <think>
Extract <EXECUTE_PYTHON>
Execute code in sandbox
